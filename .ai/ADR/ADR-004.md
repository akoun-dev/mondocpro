# ADR-004 — Architecture du système d'authentification

**Statut** : ACCEPTÉ · **Date** : 2026-09-30 · **Feature** : FEATURE-AUTH
**Décideurs** : Tech Lead + Security + DevOps/Data · **Contexte** : SPEC-AUTH

## Contexte

Mon doc Pro exige une authentification multirôle (PATIENT / NURSE / ADMIN) pour un
public ivoirien (Yopougon, Songon, PK22, N'Dotré) incluant des patients de tout âge,
avec exigence de traçabilité (médical) et paiement sécurisé futur (Tokens).

## Décisions

1. **Identifiant = numéro de téléphone** (unique) — PAS d'e-mail.
   _Raisons_ : taux d'équipement mobile > e-mail en Côte d'Ivoire ; cible tout âge ;
   prépare le OTP SMS (itération suivante) et le contact patient pour missions domicile.
2. **Sessions en base (table `Session`)** + cookie httpOnly `Mon doc Pro_session` — PAS de JWT stateless.
   _Raisons_ : révocation immédiate (déconnexion, compromise) ; traçabilité médicale
   (audit des connexions) ; simplicité. Token aléatoire 48 octets, **hashé SHA-256** en DB
   (une fuite DB ne permet pas de rejouer un cookie), expiration 30 jours.
3. **Hash bcryptjs 10 rounds** (pure JS, compatible Bun) — `scrypt` node natif écarté
   pour rester sur l'outil standard audité ; `bcrypt` natif écarté (build natif Bun).
4. **Rôles/zone en enums Prisma** (`Role`, `Zone`) — liste fermée définie par le PO ;
   validation zod en miroir côté API.
5. **Pas d'auto-inscription ADMIN** : le compte du Dr Kadjane est créé par seed
   (`.zscripts/seed_admin.ts`, mot de passe initial via `ADMIN_INITIAL_PASSWORD`,
   à changer à la première connexion — notice PO). L'API register n'accepte que
   `PATIENT` / `NURSE`. _Raison_ : surface d'attaque minimale ; le Médecin Chef
   est unique et nommé dans le cahier des charges.
6. **État client** : store **zustand** (`src/stores/auth-store.ts`) + hook `useAuth`.
   L'auth est un état d'app global (pas du server-state cacheable) → react-query
   écarté ici ; restera utilisé pour les listes (RDV, missions…).

## Conséquences

- Schéma : `User` (métier, phone unique, passwordHash, role, zone) + `Session`
  (tokenHash unique, expiresAt, cascade delete). Les modèles scaffold `Post` sont
  supprimés (0 ligne de données — vérifié).
- Layout : `lang="fr"`, métadonnées Mon doc Pro, icône = `public/img/Mon doc Pro.jpeg`
  (push PO 2b9e7b1).
- OTP SMS, reset password, OAuth : hors périmètre v1 (SPEC-AUTH §6).
